# SALTBURN CAPITAL — My Wallet v3

Application en français avec deux rubriques : budget loisirs et budget mensuel.

- Budget loisirs : enveloppe mensuelle, dépenses et solde restant.
- Budget mensuel : lignes types de charges préremplies, revenus ajoutables, montants prévus et montants réels modifiables au fur et à mesure.
- Les lignes types ajoutées sont reconduites aux mois suivants. Les montants réels sont propres au mois.
- Les données sont stockées localement dans le navigateur. Export et import JSON disponibles.
- L'application doit être servie en HTTPS pour l'installation PWA et le fonctionnement hors ligne.

Note : les données restent sur le navigateur et l'appareil utilisés ; aucune synchronisation entre appareils.
