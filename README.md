# SALTBURN CAPITAL — My Wallet v4

- Interface en français.
- Budget loisirs : montant initial, dépenses et montant restant.
- Budget mensuel : lignes de charges types reconduites chaque mois, colonnes PRÉVU et RÉEL.
- Le résumé mensuel est calculé ainsi : somme PRÉVU − somme RÉEL.
- La barre visualise la part du budget prévu déjà dépensée.
- Données stockées localement dans le navigateur.
- Export/import JSON disponible.

Le logo officiel est chargé depuis l'URL Wix fournie par l'utilisateur, avec un monogramme SVG local en secours. Le logo distant peut nécessiter une connexion lors du premier chargement.
