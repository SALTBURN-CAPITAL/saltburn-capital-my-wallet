# SALTBURN CAPITAL — My Wallet (version française)

Deux rubriques simples : Budget loisirs et Budget mensuel. Interface française, style sombre/doré, données locales au navigateur, export et import JSON.

- Budget loisirs : définir l'enveloppe du mois, enregistrer les dépenses et voir le reste.
- Budget mensuel : ajouter revenus et charges prévus, enregistrer les dépenses réellement effectuées et consulter les totaux.
- Les données sont séparées par mois et restent sur l'appareil / navigateur utilisé. Pas de synchronisation entre appareils.
- Faire régulièrement une sauvegarde JSON. Effacer les données du navigateur peut supprimer l'historique.
- PWA : à héberger en HTTPS pour installer et utiliser le mode hors ligne.
